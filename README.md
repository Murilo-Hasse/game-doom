# Panda3D FPS Project

Projeto de jogo 3D em primeira pessoa utilizando Panda3D e Bullet Physics.

## 📌 Descrição

Este projeto implementa:

- Sistema de cena 3D com modelo de mapa (.glb)
- Iluminação ambiente e direcional
- Sistema de física com Bullet Physics
- Colisão baseada em malha (terrain collision)
- Controle de jogador em primeira pessoa
- Sistema de input personalizado

## 🧰 Tecnologias

- Python 3.10+
- Panda3D
- Bullet Physics (integrado ao Panda3D)
